Política de Privacidade

Última atualização: 12 de outubro de 2026

Esta política vale para o aplicativo Robo Onde Foi Meu Imposto ("Aplicativo"), ferramenta interna usada pelo canal do YouTube Onde Foi Meu Imposto para publicar os próprios vídeos.

1. Quem usa o Aplicativo

O Aplicativo é de uso exclusivo do responsável pelo canal Onde Foi Meu Imposto. Ele não é oferecido ao público e não permite que outras pessoas façam login.

2. Dados acessados

Com a autorização do dono do canal, feita pelo login do Google (OAuth), o Aplicativo usa os serviços de API do YouTube com os escopos youtube.upload e youtube para:

  • enviar vídeos produzidos pelo próprio canal;
  • definir título, descrição, tags, idioma, visibilidade e miniatura desses vídeos;
  • consultar informações básicas do próprio canal (nome e identificador) para confirmar que a publicação vai para o canal certo.

O Aplicativo não acessa, coleta ou armazena dados de espectadores, inscritos, comentaristas ou de quaisquer outras contas.

3. Armazenamento

O token de autorização fica salvo apenas no computador do responsável pelo canal, em uma pasta local protegida. Nenhum dado obtido pela API do YouTube é vendido, compartilhado com terceiros ou usado para publicidade.

4. Serviços do Google e do YouTube

O Aplicativo usa os Serviços de API do YouTube. Ao usá-lo, aplicam-se também os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

5. Como revogar o acesso

O dono da conta pode revogar a qualquer momento o acesso do Aplicativo em myaccount.google.com/permissions. Depois da revogação, o token salvo deixa de funcionar.

6. Contato

Dúvidas sobre esta política podem ser enviadas pela página do canal: youtube.com/@ondefoimeuimposto.

7. Alterações

Esta política pode ser atualizada. A data no topo da página indica a versão em vigor.
